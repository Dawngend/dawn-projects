# dawn-projects

Small Python and web projects, built one at a time with tests.

- `job_market_scraper`: collects remote job postings from five public sources, keeps the AI, ML, data and backend roles, and writes a dashboard
- `hn_scraper`: reads the monthly Hacker News "Who wants to be hired?" threads and keeps the US-located posts
- `safe_job_check`: paste a job post and see its warning signs
- `profile_builder`: builds a GitHub profile README from a small JSON file
- `market_notebook`: a notebook that explores the job postings data

Each project folder has its own README with the run and test steps.
